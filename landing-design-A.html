Landing Page Redesign — Design A

A light, airy, Apple-inspired layout. Hero sits comfortably below the phone status bar, the bottom tab bar is solid (fixed) so scroll content never bleeds through, and cards use compact two-column rows on phone / four across on laptop.

Fixes this design demonstrates: ① Hero pushed below the status bar with safe-area padding — never hidden behind the Wi‑Fi/notification area. ② Bottom tab bar is a fixed, solid surface — Home/Search/Match/Messages/Profile always stay in place while scrolling. ③ Agent cards redesigned into a compact, scannable row (avatar + name left, 3-stat strip) instead of a bulky stacked card.
